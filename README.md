# Lev Cursor Plugin

A [Cursor](https://cursor.com) plugin that connects to [Lev](https://www.lev.com), a commercial real-estate (CRE) debt-placement platform. Brokers and sponsors use Lev to structure deals, match them to lenders, track placements through outreach pipelines, and compare term sheets against live market base rates.

## What it does

Once connected, AI assistants in Cursor can:

- Search deals, contacts, companies, lenders, placements, and term sheets
- Create and update deals, contacts, and companies
- Move deals through pipelines
- Compare term sheets and look up live CRE market base rates
- Switch between Lev accounts you have access to

## Installation

1. Open Cursor settings
2. Navigate to **Tools & MCPs** (or **Plugins**)
3. Click **Browse Marketplace**
4. Search for "Lev"
5. Click **Install**, then **Connect** — a browser window opens for sign-in via Lev's OAuth flow

A Lev account is required. Sign up at [lev.com](https://www.lev.com).

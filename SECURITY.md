# Security Policy

## Reporting a Vulnerability

Please do not open public GitHub issues or pull requests for security issues — that exposes the problem to anyone watching this repository.

If you discover a security issue in:

- This plugin manifest repository, or
- The Lev MCP server it points at (`https://mcp.lev.com/mcp`)

email **help@lev.com** with details. Our team will triage your report and respond.

Thank you for helping keep Lev users safe.
